# Informe ejecutivo

## Qué se observó

La conversión no depende de una sola variable. La mayor fricción aparece en sesiones móviles con carga lenta y costo de envío relativamente alto. Esto no significa que esas variables sean la causa única, pero sí que son segmentos adecuados para priorizar experimentos.

## Qué haría primero

1. Medir y mostrar el costo estimado de envío antes del checkout para reducir la sorpresa final.
2. Priorizar mejoras de rendimiento en la vista de carrito móvil.
3. Diseñar una prueba A/B de envío gratis con monto mínimo, controlando el margen.
4. Implementar un flujo de recuperación de carrito para usuarios que acepten comunicaciones.

## Criterio de éxito

El resultado de cada prueba debe evaluarse por conversión, ingreso por sesión, margen bruto y posibles efectos sobre devoluciones. Una mejora de conversión que reduzca el margen no debe considerarse automáticamente exitosa.
